# Kabadi Setu — KabadiSetu

**Smart India Hackathon 2026 — Problem Statement #26229**
**"Kabadiwala Connect — Bringing the Informal Collector into the Formal Recycling Chain"**

Built by **Team CROWNX**

---

## About

KabadiSetu digitizes the missing link in India's e-waste recycling chain: the handover between informal scrap collectors and authorized recyclers. Existing platforms only digitize the household → collector sale; KabadiSetu focuses on collector → authorized recycler, with a Capture → Value → Connect → Handover → Sync & Pay workflow.

The app is fully localized in **Marathi (default), Hindi, and English**.

## Current Status — v0.1.0

This release is a **working UI/navigation prototype** demonstrating:
- Splash, onboarding, and role-selection flow (Collector / Authorized Recycler)
- Role-based module dashboards
- Full trilingual interface

Core feature logic (AI-based scrap categorization, live pricing, GPS-verified handover, payment sync) is planned for upcoming releases — see [Releases](../../releases) for version history.
